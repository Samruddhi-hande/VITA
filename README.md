# QuickGPT ⚡🤖  
### Project: VITA

QuickGPT is an AI-powered chat application developed under the **VITA project**.  
It offers a modern ChatGPT-like experience with support for **text, image, and video interactions**, along with community sharing and credit-based plans.

---

## 🚀 Features

- 💬 **Interactive Chat Interface**
  - ChatGPT-style UI
  - Auto-scroll to latest messages
  - Clear separation of user and assistant messages

- 📝 **Markdown & Code Support**
  - Markdown-rendered responses
  - Syntax highlighting using **PrismJS**

- 🖼️ **Image & 🎥 Video Messaging**
  - View images and videos directly inside chat
  - Option to publish generated media to the Community section

- 🌍 **Community Section**
  - Public gallery for published images and videos
  - Hover effects with creator attribution
  - Media opens in a new tab

- 💳 **Credits & Plans**
  - Multiple credit plans
  - Highlighted premium plan
  - Fully dark-mode compatible UI

- 🌗 **Dark / Light Mode**
  - Smooth theme switching
  - Custom glow shadows in dark mode

- ⏳ **Loading Experience**
  - Animated loading screens during transitions and data fetching

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite  
- **Styling:** Tailwind CSS  
- **Routing:** React Router DOM  
- **Markdown Rendering:** react-markdown  
- **Syntax Highlighting:** PrismJS  
- **Date Handling:** moment.js
